# MYMWN KLASH Video Player PRO

## الفيديوهات
التطبيق يعرض الفيديوهات **من الهاتف فقط** باستخدام MediaStore. لا توجد صلاحية `INTERNET` في AndroidManifest، لذلك النسخة الحالية لا تعتمد على فيديوهات من الإنترنت أو رفعها للسحابة.

## الإضافات
- Reels عمودي بالسحب للأعلى والأسفل.
- تشغيل تلقائي وتكرار.
- **ضغطتين على الفيديو = ❤️ إعجاب** مع قلب متحرك.
- حفظ الإعجابات محلياً.
- سرعة تشغيل: 0.5x / 1x / 1.25x / 1.5x / 2x.
- كتم/تشغيل الصوت.
- قفل اللمس أثناء المشاهدة.
- أزرار تفاعلية بتأثير ضغط.
- شاشة ترحيب فخمة باسم كلاش.
- رسالة ترحيب عشوائية تتغير **في كل فتح للتطبيق**.
- أقسام الرئيسية، Reels، الإعجابات، فيديوهات الجهاز، حول المطور.
- Telegram: `@YM_IBB`.
- موارد PNG حقيقية داخل `res/drawable`.
- AndroidX Media3 / ExoPlayer.
- Android 7+ ودعم RTL.
